Аналитик, фокус — продуктовая и BI-аналитика. Строю анализ от бизнес-вопроса до проверяемого вывода: с расчётом статистической значимости, честным разбором ограничений метода и количественной оценкой эффекта на бизнес, а не только описательными графиками.

### 🎯 Портфолио для продуктового аналитика

**[AB-test-reactivation](https://github.com/syulzhins/AB-test-reactivation)** — A/B-тест реактивационной рассылки: расчёт необходимого размера выборки *до* запуска, z-тест для двух пропорций, рамка принятия решения (практическая значимость, гвардрейл-метрики, риск peeking).

**[Telco-Churn-Analysis](https://github.com/syulzhins/Telco-Churn-Analysis)** — анализ оттока клиентов: проверка факторов оттока тестом хи-квадрат, кривая удержания Kaplan-Meier, модель с precision/recall/ROC-AUC и бизнес-интерпретацией коэффициентов.

**[RFM-Customer-Segmentation](https://github.com/syulzhins/RFM-Customer-Segmentation)** — сегментация клиентской базы по ценности: вклад каждого сегмента в выручку, статзначимость различий между сегментами, приоритизация маркетингового бюджета.
